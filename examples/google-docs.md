# The Google Docs binding — why there is no example file here

Google Docs offers no text-layer carrier: hidden text does not exist in
the format, and HTML comments do not survive import. The binding in
`WILL-1.md` is therefore an API design over named ranges — Google
maintains their positions through edits — and it remains a draft until
that carrier can honestly meet the standard's bar.

One executed fact belongs beside that honesty: importing a willed DOCX
into Google Docs and re-exporting it **silently strips the will**
(verified 2026-08-31 against real Google Docs). The world's most-traveled
DOCX conversion is a WILL LOST hop, and a Will-aware pipeline crossing it
must say so.
