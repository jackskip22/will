# Changelog

## 1.0.0 (2026-10-29)

- Will/1: `edit`, `append` and `keep` regions in Markdown, with markers any editor can keep.
- `will.mjs`: the MIT reference. `node will.mjs check vectors.json` checks a host against the normative vectors.
- `node will.mjs compare before.md after.md` judges an edit; `action.yml` runs the same check on a pull request.
- Python and Go hosts with their adapter vectors.
